# 真相ページ仕様書

## 1. ページ概要

`truth.html`は、御影山診療所の本当の役割と、地下で保護されている患者たちの存在を明らかにする最終ページです。

このページは、プレイヤーがSTEP3を完了し、`mikageClinicPhase`が`phase3`になった場合のみ閲覧可能にしてください。

真相ページは、ホラーや残虐表現で恐怖を煽るのではなく、以下の感情を残す構成とします。

- 患者たちは現在も生きている
- 施設は隔離と隠蔽を行っている
- 一方で、患者の生命を守るための場所でもある
- 院長の行為は単純な善悪では判断できない

## 14. X共有機能

ボタン文言：

`発見した記録をXで共有する`

XのWeb Intentを使用してください。

共有文テンプレート：

`山間の診療所を調査していたら、公開されていない地下施設の記録を見つけました。`

`患者たちは、今も地下で生きています。`

`#御影山診療所 #ARG`

共有文には必ず以下を含めてください。

1. ARGサイトのURL
2. 元の告知投稿のURL

### 設定方法

JavaScript内に以下の定数をまとめてください。

```js
const SHARE_CONFIG = {
  originalPostUrl: 'REPLACE_WITH_ORIGINAL_POST_URL',
  siteUrl: window.location.origin + window.location.pathname.replace(/truth\.html$/, ''),
};
```

元投稿URLが未設定の場合は、開発用コメントを残してください。

投稿文の最後に以下を追加してください。

`元の投稿：${SHARE_CONFIG.originalPostUrl}`

`サイト：${SHARE_CONFIG.siteUrl}`

共有ボタンを押した場合は、新しいタブでX投稿画面を開いてください。

`window.open`には`noopener,noreferrer`相当の安全対策を行ってください。

## 17. デバッグモード修正

既存のデバッグモードに以下の修正を加えてください。

### 改変演出のショートカット修正

現在、`Alt / Option + Shift + A`で演出が再生されないため修正してください。

対応条件：

- `keydown`を`window`または`document`へ1回だけ登録
- `event.code === 'KeyA'`を使用
- `event.altKey && event.shiftKey`を判定
- 大文字小文字や日本語入力状態に依存しない
- 入力欄、textarea、select、contenteditable内では無効
- デバッグモード中のみ有効
- `event.preventDefault()`を適切に使用
- phaseは変更せず、共通の改変演出関数だけを呼び出す
- 二重登録を防止する

### デバッグパネル表示・非表示ショートカット

デバッグモードが有効な場合、以下のキーでパネル表示を切り替えてください。

`Alt / Option + Shift + D`

判定：

- `event.code === 'KeyD'`
- `event.altKey && event.shiftKey`

挙動：

- 表示中なら非表示
- 非表示なら表示
- 状態を`sessionStorage`へ保存

キー：

`mikageClinicDebugPanelVisible`

値：

- `true`
- `false`

### 補助ボタン

デバッグパネル内にも以下を必ず設置してください。

- `改変演出を再生`
- `パネルを隠す`

`パネルを隠す`を押した後も、`Alt / Option + Shift + D`で再表示できるようにしてください。

### デバッグモードの有効化

`?debug=1`

または、すでに`sessionStorage.mikageClinicDebug === 'true'`の場合。

デバッグモード終了ボタンでは以下を削除してください。

- `mikageClinicDebug`
- `mikageClinicDebugPanelVisible`

## 20. 禁止事項

- phase3未満で真相本文を表示しない
- 元投稿URLを共有文から省略しない
- 患者を怪物のように描写しない
- 血液や残虐表現を使用しない
- 院長を単純な悪役として断定しない
- 真相ページを黒一色のホラーサイトにしない
- X共有時にphaseや個人情報を送信しない
