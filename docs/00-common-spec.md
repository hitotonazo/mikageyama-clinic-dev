# 山間の診療所 ARGサイト
## 共通仕様書

---

# プロジェクト概要

本サイトは「山間の診療所」をテーマにした常設型ARGサイトです。

プレイヤーは一見普通の地域密着型クリニックのホームページを閲覧しながら、少しずつ違和感を発見し、サイトが段階的に改変されることで真相へたどり着きます。

プレイ時間は20〜60分程度を想定します。

---

# デザインコンセプト

「山に囲まれた、小さな地域診療所」

ホラーサイトではなく、
地域住民から信頼されるクリニックをイメージしてください。

デザインは

・温かい
・安心感
・清潔感
・余白が多い
・自然を感じる

ことを重視してください。

参考イメージ

・淡いグリーン
・アイボリー
・木目
・植物
・自然光

---

# デザイン品質

以下を重視してください。

・実在するクリニックサイトレベルの完成度
・テンプレート感を出さない
・余白を広く取る
・写真を大きく使用する
・カードデザインを使用する
・角丸を使用する
・柔らかい影を付ける
・セクション毎に背景色を少し変える

デザインは

「優しい」「温かい」

印象を最優先してください。
